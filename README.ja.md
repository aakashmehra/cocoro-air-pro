# Cocoro Air Pro

**シャープのエアコン向けの、シンプルで速いカスタムアプリです。** 非公式アプリです。

自宅の Wi‑Fi から直接エアコンを操作できます。アカウント不要、ログイン不要、クラウド不要。スケジュール、お気に入り、すっきりした Liquid Glass デザイン。

[English → README.md](README.md)

---

## 作った理由

シャープのエアコンを、アカウントにログインせず、操作のたびにクラウドを経由することもなく使いたかったからです。

そこで自分で作りました。Cocoro Air Pro は自宅の Wi‑Fi 上でエアコンと直接やり取りします。アプリを開けばエアコンを自動で見つけて、すぐ使えます。新しいエアコンを Wi‑Fi につなぐ設定もアプリ内でできるので、公式アプリは必要ありません。

## 2つのバージョン

| | **Wi‑Fi のみ** (`CocoroAirPro-WiFi.ipa`) | **アカウント版** (`CocoroAirPro-Account.ipa`) |
|---|---|---|
| ログイン | なし | COCORO MEMBERS アカウント、自宅 Wi‑Fi、デモのいずれか |
| 外出先から操作 | できない | ログイン時はできる |
| スケジュール | ショートカットのオートメーション | ログイン時はシャープのクラウドタイマー、自宅 Wi‑Fi ではショートカット |

ほとんどの方は **Wi‑Fi のみ** がおすすめです。

## 機能

- **自動で接続。** 自宅の Wi‑Fi でエアコンを見つけ、ルーターが新しいアドレスを割り当てても自動で見つけ直します。
- **アカウント不要、ログイン不要。** すべてスマホと自宅のネットワークの中で完結します。
- **Wi‑Fi 設定をアプリに内蔵。** 新しいエアコンを、ルーターの接続ボタン、またはエアコン自身の Wi‑Fi で接続できます。公式アプリは不要です。
- **すべての操作:** 電源、冷房、暖房、除湿、送風、自動、温度(対応機種は 0.5℃ 単位)、風量、上下・左右の風向、プラズマクラスター、やさしい風。
- **スケジュール:** 決まった時刻・曜日に、好みの設定で運転開始、または停止。アプリを閉じていても動きます。
- **お気に入り:** いつもの設定を保存して、ワンタップで呼び出し。ショートカットや Siri からも使えます。
- **ガラスのタブバー**(操作、スケジュール、お気に入り、設定)、ダイヤルと風のアニメーション、Inter フォント、ライト・ダークモード対応。
- 最初の画面の **ⓘ** で使い方とトラブル対処を確認できます。

## 対応エアコン

| エアコン | 状況 |
|---|---|
| Wi‑Fi 内蔵のシャープ製エアコン | 自宅のエアコンで開発・動作確認済み |
| 家電ワイヤレスアダプターを使うシャープ製エアコン | 動くはずですが未確認 |

エアコンが接続できるのは **2.4 GHz** の Wi‑Fi だけです。ルーターに2つのネットワーク名がある場合は 2.4 GHz の方(名前の最後が `-G` や `-2G` のことが多いです)を使ってください。

ほかの機種で試した方は、Issue で結果を教えてください。

## ⚠️ スケジュールには iPhone が自宅にある必要があります

シャープのエアコンには Wi‑Fi から設定できる本体タイマーがないため、**Wi‑Fi のみ** 版はスケジュールを iPhone の **ショートカット** アプリで実行します。スケジュールを作ったあと、ショートカットで一度だけ設定すれば、アプリを閉じていても毎日その時刻に動きます。その時刻に iPhone が自宅の Wi‑Fi につながっている必要があります。

外出中も動くスケジュールが必要な場合は、**アカウント版** でログインしてください。タイマーがシャープのサーバーで動きます。

## インストール

### IPA をサイドロード
[Releases](../../releases) から `CocoroAirPro-WiFi.ipa`(または `CocoroAirPro-Account.ipa`)をダウンロードし、ご自身の Apple ID で [AltStore](https://altstore.io) または [Sideloadly](https://sideloadly.io) を使ってインストールしてください。IPA は未署名なので、これらのツールがあなたの端末用に署名します。無料の Apple ID の場合は7日ごとに更新が必要です。

ヒント:更新はいつも同じツールで行ってください。AltStore と Sideloadly ではアプリ ID が少し違うため、ツールを変えると上書きではなく2つ目のアプリとして入ってしまいます。

### ソースからビルド
Xcode と Node.js が入った Mac が必要です。

```bash
git clone https://github.com/aakashmehra/cocoro-air-pro.git
cd cocoro-air-pro
npm install
WIFI_ONLY=1 npx expo run:ios --device   # Wi‑Fi のみ版
npx expo run:ios --device               # アカウント版
```

> **Expo Go**(`npx expo start`)でも動きますが、Expo Go はローカルネットワークの機器と通信できないため、**デモモード** のみです。

## 使い方

1. **エアコンを Wi‑Fi につなぎます**(つながっていれば不要)。最初の画面で **Set up Wi‑Fi** をタップ:
   - **ルーターのボタン:** リモコンの **メニュー** を3秒押すとコネクトランプが点滅します。2分以内にルーターの Wi‑Fi 接続ボタンを押します。
   - **エアコン自身の Wi‑Fi:** リモコンの **停止** を、`AP-SHARP-` と番号のネットワークが現れるまで押し続けます。設定アプリでそのネットワークに接続してアプリに戻り、自宅の Wi‑Fi の名前とパスワードを入力します。
2. 自宅の Wi‑Fi でアプリを開き、iPhone に聞かれたら **ローカルネットワーク** へのアクセスを許可します。エアコンが自動で見つかります。
3. **操作:** ダイヤルをドラッグするか、プラス・マイナスで温度を設定。モード、風量、風向を選びます。
4. **お気に入り:** **Save current settings** をタップ。あとはお気に入りをタップするだけで適用されます。
5. **スケジュール:** **New schedule** をタップし、時刻・曜日・動作を選んで、一度だけの **Finish in Shortcuts** の手順に従います。
6. **設定:** 接続状態の確認や切断ができます。
